# Hero Analysis for the Future No. 13 (Dekunotebook)

It's ok! Why? Because I am here!

## 📖 About the Project
The purpose of this project is to allow you to literally get inside Deku's notebook. It is an exploration of what it would feel like if Deku existed in this world, if you got to stand right next to him, and if he handed you his notebook to examine every single page carefully. 

This is about bringing that feeling to life—creating an immersive, interactive experience of the *My Hero Academia* universe. This project falls under the category of digital fanart.

## 🔗 Origin & Evolution
This project stems originally from the Flexbox project in *The Odin Project*. While working through the curriculum, seeing the word "hero" in the assignment context immediately sparked the idea. Everything clicked: this concept was meant to be the true starting point for Deku's notebook. To preserve the original *odin-recipes* foundation while expanding the scope, this standalone repository was created to bring the notebook to life as a dynamic, responsive web application using CSS Flexbox layouts and interactive JavaScript elements. I incorporated everything, and even more that I have explored in The Odin Project Foundations in oder to bring my vision to life.
